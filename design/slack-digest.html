Visual language

  • Amber border + pill — Push today. Time-sensitive but positive: there's something to do.
  • Coral border + pill — Stalled / At risk. Same color to indicate "needs attention."
  • Mint (not shown) — Closed-won, healthy renewal. Reserved for the weekly recap, not the daily digest.
  • Indigo signal dot — appears on the bot avatar and at the start of section headers. Only branded touch on this surface.

Open questions for W3 review (CTO + CEO sign-off needed)

  • Q1. Do we send one message with all blocks (current proposal) or one thread + one block per item? Threads are quieter but lose at-a-glance scanability.
  • Q2. Should "Draft follow-up" open the draft in a Slack modal or push to a web app? Modal is faster; web app gives more editing room.
  • Q3. Daily cap on number of items shown — 6 hard cap or expandable "see more"? Recommend hard cap (Miller's Law: working memory ~7); expand surfaces "Stalled (2)" as a single block.
  • Q4. Time zone & quiet hours — default 8:30 AM local Mon–Fri; user-configurable. Should we suppress on holidays automatically?
